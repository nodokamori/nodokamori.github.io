# nodokamori

A minimal personal landing page using an original photograph taken at Tiger Mountain, Washington.

## Publish on GitHub Pages

1. Sign into GitHub as `nodokamori` and create a **public** repository named `nodokamori.github.io`.
2. Upload `index.html` and `forest.jpg` into the repository root (not inside a folder).
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, and save.
4. Visit https://nodokamori.github.io after deployment finishes.
5. When ready to connect the domain, add `nodokamori.com` in **Settings → Pages → Custom domain**, then configure Namecheap DNS according to GitHub's current Pages documentation. Preserve existing iCloud email DNS records.

The site has no JavaScript, analytics, external fonts, or tracking.
